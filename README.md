# Basho Valley Education Foundation (BVEF)

Official repository for the **Basho Valley Education Foundation (BVEF)** web platform.

## Project Status
**Current Phase:** Pre-Implementation (Documentation, Planning & Asset Organization).
No application code, backend, database, or deployment configuration has been initialized yet. See [docs/PROJECT_STATUS.md](./docs/PROJECT_STATUS.md) for details.

## Repository Structure
- `assets/source/` — Original foundation documents (`About-Us.pdf`, `Photo-Collection-for-AF.pptx`).
- `assets/photos/` — Extracted and categorized foundation & village photography.
- `docs/` — Architecture, requirements, design system, security, testing, and status documentation.
- `docs/decisions/` — Architecture Decision Records (ADRs).
- `.agents/rules/` — Antigravity workspace rules for coding, frontend, backend, database, and security.
- `.agents/skills/` — Reusable Antigravity workflows (`SKILL.md`).

## Prerequisites (Target Environment)

- Node.js `v22.18.0`
- npm `10.9.3`
- Git `2.48.1`
